# hhhhhh

Animated text with spring motion

A Remotion project created with **Motion Studio**.

## Render

```bash
npm install
npm run build
```

The video is written to `out/video.mp4` (1920×1080, 30 fps, 5 s).

## Preview

```bash
npm start
```

Opens Remotion Studio in your browser.

## GitHub Actions

This project includes `.github/workflows/render.yml`. Push it to
GitHub, then tap **Render** in Motion Studio.
